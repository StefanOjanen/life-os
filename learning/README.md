## How a lesson works

1. Open the track file, find the current module and the next unchecked lesson.
2. Write the lesson (max 350 words): the core idea, one number or equation worth remembering, one primary source, one check question.
3. Append to the track's log: date, title, check question.
4. When the owner answers a check question, note the answer and adjust the pace.

Accuracy matters more than coverage: if a figure is uncertain, say so or leave it out.
